# PadosiPro Backend

Backend API for the PadosiPro mobile application.

## Tech Stack

- Node.js 22
- TypeScript
- Express
- PostgreSQL
- Prisma ORM
- JWT authentication
- bcryptjs password hashing
- Zod validation
- Nodemailer
- Mailpit
- Docker Compose
- Vitest
- Supertest

## Requirements

- Docker
- Docker Compose
- Node.js 22+ (for local development/tools)

## Run with Docker

From the backend directory:

```bash
docker compose up --build
